# User profile and defaults

Use these preferences only when the task and active repository do not specify a different choice.

## Working style

- Primary use: personal work.
- Primary coding mode: maintain existing repositories.
- Secondary coding mode: create new projects.
- Communication language: Chinese by default; preserve the language required by the deliverable or repository.
- Prefer concise progress updates and an evidence-backed final summary.

## Engineering profile

- Primary stack: TypeScript, Next.js, React, and Node.js.
- Common frontend tools: Tailwind CSS, Zustand, TanStack Query.
- Common backend and data tools: Express, SQLite, MySQL, Redis, MongoDB, Elasticsearch, RabbitMQ.
- Common validation tools: Vitest, Playwright, Lighthouse CI, linting, type checking, and production builds.
- Common infrastructure: Docker and Docker Compose.
- Secondary environments: Java, Python, Jupyter Notebook, and JavaScript.

For a greenfield web project with no contrary requirement, prefer Next.js, TypeScript, React, Tailwind CSS, Vitest, Playwright, and pnpm. Add databases, caches, search engines, queues, or microservices only when requirements justify their operational cost.

## Repository and documentation preferences

- Repository-local instructions and conventions override this profile.
- Confirm executable commands from configuration files rather than relying only on prose documentation.
- Prefer updating a relevant existing document over creating another status or troubleshooting summary file.
- Separate verified implementation behavior from README claims and roadmap intentions.
- Keep generated files and comments proportionate to their ongoing maintenance value.

## Editable personal preferences

The user may extend this section with non-secret preferences such as:

- Preferred UI style and accessibility targets.
- Preferred commit-message convention.
- Preferred hosting and database providers.
- Document and presentation style.
- Investment universe, time horizon, and analytical framework.

Never place account credentials or authentication material in this file.
