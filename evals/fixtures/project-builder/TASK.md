# Personal task CLI

In the provided empty project directory, build a personal task CLI from scratch using only the Python standard library. No dependency installation, network access, Git commit, or external service is authorized.

It must add a task, list tasks, and mark one complete. Data must survive separate command invocations. Empty or whitespace-only titles and nonexistent IDs must produce clear errors without damaging saved tasks. Keep this a local single-user utility, not a web application. Choose and document a simple command syntax and storage location; tests must use isolated data.

Implement and verify the first release, then explain how to start it, run its tests, and continue maintenance. The request already establishes the product and stack; ask only if a remaining consequential decision genuinely prevents progress.
